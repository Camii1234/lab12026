# lab12026

Proyecto del Laboratorio 1 de Arquitectura de Software.

El backend conserva la implementación original del profesor y agrega únicamente:

- `PUT /api/customers/{id}` para actualizar clientes.
- `DELETE /api/customers/{id}` para eliminar clientes.

La aplicación utiliza Spring Boot, JPA y MySQL en el backend, y React, Vite y Axios en el frontend. No requiere login ni token.
